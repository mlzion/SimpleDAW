# Licensing and redistribution

**A freely distributed open-source build is feasible in principle.** The candidate build uses AGPLv3 for JUCE and the combined distribution, and GPLv3 for Tracktion Engine and the covered files in JUCE's bundled VST3 SDK. GPLv3 §13 and AGPLv3 §13 allow combining works under those two versions. Each covered part keeps its applicable licence. The repository has no SimpleDAW licence grant, and its release notices and corresponding source have yet to be prepared. Public repository visibility provides access to the source. A licence grant is required for open-source redistribution. [GPLv3](https://www.gnu.org/licenses/gpl-3.0.en.html) · [AGPLv3](https://www.gnu.org/licenses/agpl-3.0.en.html)

[Pinned SDK licence](https://github.com/juce-framework/JUCE/blob/19edd538429c93d277bf95b55aaa7e3eb545f951/modules/juce_audio_processors/format_types/VST3_SDK/LICENSE.txt) · [Current SDK licence](https://github.com/steinbergmedia/vst3sdk/blob/master/LICENSE.txt) |

## Before uploading a downloadable EXE

1. Have the rights holder choose and apply a compatible licence for SimpleDAW's original code and verify rights for any contributed code. AGPLv3 is the proposed route for the default build.
2. Audit the linked components for the exact source revision and configuration, including JUCE and Tracktion bundled code and the static MSVC runtime. Confirm the Microsoft toolchain redistribution terms and the GPL/AGPL System Library exception as applicable to the shipped Windows build. Retain applicable copyright, licence, attribution and warranty notices. Publish GPLv3 and AGPLv3 texts and per-component notices with the distribution materials.
3. Make exact Corresponding Source available alongside the binary under an applicable GPLv3 §6 / AGPLv3 §6 method. For an online release, provide equivalent source access at no extra charge and clear directions alongside the binary. Include the SimpleDAW sources, exact covered dependency sources and changes, and scripts needed to build and install the covered executable. Preserve access for the required period. The EXE download can contain only `SimpleDAW.exe` if the accompanying release materials supply the applicable notices and source access without adding files needed at runtime.
4. Start with the default WASAPI-capable build. To publish an ASIO variant, resolve the exact SDK licence and source obligations separately.

Static linking removes app-local DLL deployment for the bundled modules and MSVC runtime. It still incorporates dependency code into the executable, so the combined-work obligations and component notices apply. GitHub Actions can build and test privately on the runner. Exposing an executable as an Actions artifact is a distribution decision governed by the same obligations as a release download. The workflow has no upload step until the project adopts a licence and completes the release materials above.
