# Licensing considerations

- **JUCE.** The pinned JUCE 8 modules offer AGPLv3 and commercial terms. A commercial JUCE licence may be required. Determine the terms that cover development and any executable distribution. [Pinned JUCE licence](https://github.com/juce-framework/JUCE/blob/19edd538429c93d277bf95b55aaa7e3eb545f951/LICENSE.md)
- **Tracktion Engine.** The pinned release offers GPLv3-or-later and a separate commercial licence. Redistribution of a combined executable must satisfy the applicable terms of both Tracktion and JUCE and include applicable third-party notices. [Tracktion Engine licence](https://github.com/Tracktion/tracktion_engine/blob/v3.2.0/LICENSE.md)
- **VST3.** The SDK bundled with the pinned JUCE revision offers the proprietary Steinberg VST3 licence or GPLv3 for covered files. Newer SDK releases offer MIT terms. Review use of the VST name and marks separately. Installed plugins have their own terms. [Pinned SDK licence](https://github.com/juce-framework/JUCE/blob/19edd538429c93d277bf95b55aaa7e3eb545f951/modules/juce_audio_processors/format_types/VST3_SDK/LICENSE.txt) · [Steinberg VST3 SDK](https://github.com/steinbergmedia/vst3sdk)
- **ASIO.** The prototype builds its ASIO backend only when the builder supplies the headers. Review the terms packaged with the exact SDK used for building and distributing an ASIO-enabled executable. The interface vendor supplies the driver separately. [Steinberg developer resources](https://www.steinberg.net/developers/)
- **MP3.** No encoder is included. LAME's library licensing and the terms of any external executable or Windows codec are part of selecting a distribution approach. [LAME project](https://lame.sourceforge.io/)

The starting repository has no SimpleDAW licence. Confirm the project's licensing and applicable notices before publishing a downloadable executable. The default workflow builds and tests the executable on the runner. Artifact upload is available via a manual workflow run with the redistribution option enabled.
