## Implementation work
1. **Inspector selection foundation.** Track vs clip Inspector follows current focus, respects independent Track List and Timeline selections, standard UAT highlight/focus hierarchy. One selected clip/track displays controls; no speculative multi-selection parameter editor. Editor closed by default; single click inspect, double-click opens relevant bottom editor only when available.
2. **Track Inspector.** Build accepted sections in order: identity/name/color; input; large M/S/Arm; integrated tall volume fader and independent live meter; pan; built-in 3-band EQ; effect chain with add/remove/reorder/enable; Volume/Pan automation access without building editor; exclusive output Master/Bus 1/Bus 2. Respect 8 effect slots and independent built-in EQ. Include per-track MIN/MAX and track settings COPY/APPLY contract if available; do not replace UAT full-track copy/paste. Implement routing/bus backend only to extent already supported; report missing prerequisite rather than fabricate buses.
3. **Audio Clip Inspector.** Common clip name/type/track/start/length/color; MIX/REPLACE toggle; gain, fade-in/out sliders in seconds; non-destructive trim indicators; cyan gain/fade waveform overlay MAX only. Preserve MAX/MIN waveform alignment and selection visuals.
   - For MIDI tracks, add input device, Omni or 1-16 input channel and 1-16 output channel (default Channel 1) to the Track Inspector. Retain Arm and Monitor. Verify that moving a clip to another MIDI track changes its playback channel and that Piano Roll audition follows the same routing.
4. **MIDI Clip Inspector.** Common fields; playback-only Velocity 0–200% and Transpose ±24 semitones; note data unchanged; bounds handling; non-destructive clip trim and playback cutoff. Keep channel controls on the Track Inspector only. Piano Roll implementation remains a separate workstream.
5. **Duplicate/Clone/Unclone.** Implement source-linked clone family, parent promotion on deletion, shared parent edits and color, numbered chain badges MAX only, independent clone position/compatible track routing; Inspector UNCLONE. DUPLICATE independent. Both create at timeline cursor and preserve loop arrangement. Undo/save/reopen all relationships. No independent clone edits beyond position/track.
6. **Loop.** Audio/MIDI Loop toggle and positive count, pattern length captured from current clip, repetitions rightward, SIZE changes pattern and total follows count, disable restores single pattern. MAX = at boundaries; MIN no markers. Repetitions not independently selectable/editable. Disable audio fade controls during loop, preserve values. Preserve overlap MIX/REPLACE precedence.
7. **MIDI import.** Keep Insert → MIDI Clip and File → Import Audio. Remove only the obsolete Insert Audio / Audio File command. File → Import MIDI places single-channel material at the cursor on the selected MIDI track. Follow the [routing amendment](../specifications/midi-track-routing.md) for multichannel import and project migration. Until lossless multichannel handling is available, reject unsupported files before editing.
8. **Serialization and atomicity.** Persist all new track/clip/clone/loop values, shared source identity and parent promotion. Maintain one undoable transaction per action and compatibility checks. Reject invalid moves/imports/edits without partial state mutation.

## Acceptance / regression checks
- Inspector selection/focus and track/clip switch; closed-by-default editor and double-click behavior; existing UAT actions, transport, shortcuts and Track List selection unchanged.
- Track: identity/type, input, M/S/Arm, fader/meter independence, pan, 3-band EQ, 8 effects maximum and enable/reorder/removal, output routing, saved values. E1 shared IDs survive save/reopen.
- Audio: gain/fades, seconds constraints, disabled fades under Loop, MIX/REPLACE precedence, MAX cyan envelope/trim squares, MIN waveform without indicators, undo and reopen.
- MIDI: velocity 0/100/200% output, note source unchanged, transpose ±24, MIDI pitch/velocity bounds, trim/crossing note cutoff, undo and reopen.
- Clone: linked edits/name/color/trim/loop propagate; independent selection/move to compatible track; destination processing; numbered badges only MAX; UNCLONE; parent deletion/promotion; undo/save/reopen. Duplicate remains independent, including copied loop settings.
- Loop: count 1 and >1, rightward repetition, SIZE changes source pattern and total, count changes total, OFF restores single length, = markers only MAX and only at loop boundaries, clone loop inheritance, audio fade controls disabled and restored.
- Import: verify single-channel playback on the destination track output channel, plus undo and save/reopen. Verify unsupported input leaves the edit intact. For multichannel support, verify an aligned part per source track/channel, with notes, controllers and other source events preserved. Recheck Insert → MIDI Clip and File → Import Audio.
- Regression: 24-track limit, audio/MIDI compatibility, UAT MOVE/SIZE/SPLIT/TRIM where implemented, clipboard semantics, effects E0 tests, project round-trip, no Windows /MT routine job.
