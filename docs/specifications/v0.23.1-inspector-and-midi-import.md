# SimpleDAW v0.23.1 — Inspector, Clip Linking and MIDI Import Decisions
Status: **ACCEPTED DESIGN — NOT IMPLEMENTED**. Recorded 21 November 2026. This is the latest authority for v0.23.1 where older PDFs or supplements conflict. Preserve historical master PDFs unchanged; incorporate this addendum by reference.

## Device Setup acceptance corrections

Setup refreshes installed audio backends when opened and when Refresh Devices is pressed. Refresh preserves the active configuration and saved device settings. Selecting a backend updates its device choices from a fresh scan. Audio controls read back the active configuration after a change, and MIDI input check marks update after enable or disable. The standard Windows package uses its supported Windows audio backends. ASIO remains an optional SDK-enabled build with an installed vendor x64 driver.

## Live acceptance correction decisions

- During playback, Volume, Pan, track EQ, Audio Clip Gain, MIDI Velocity and Transpose respond while dragging. Each completed gesture has one Undo step. MIDI changes affect subsequent playback notes while preserving the source sequence.
- Clip Mute is independent of track mute and follows linked clone edits. Track EQ Bypass preserves the three band settings. E1 and Inspector share the insert bypass state. Both bypass controls work during playback.
- SPLIT and TRIM require one independent Audio or MIDI clip and Timeline focus. SPLIT uses the snapped interior cursor and selects both results. TRIM retains the intersection with a nonempty ruler selection and preserves hidden source. The original parent and all clones must be independent before either operation.
- The native ADD EFFECT menu offers Reverb and Compressor within the existing eight-slot limit. The editor closes when another track, a clip, or an unrelated Inspector control is selected. Effect chain controls remain available, and a double-click on another effect switches the editor to that instance.
- MIDI Start and Length remain read-only. Inspector shows TRACK or CLIP under its heading. The name field has a visible edit boundary and the Inspector scrollbar is approximately 22 px.

## Scope and integration
- Implement useful first-iteration Track, Audio Clip and MIDI Clip Inspectors, with large controls, legible fonts and mouse-friendly targets. Avoid unrelated new editors or speculative features.
- Inspector follows active focus/selection (Editing Windows > Inspector > Timeline > Tracks). Track and clip selections remain independent. Single-click selects and inspects. While Inspector has focus, its single target’s background pulses smoothly between dim and bright selected colors about once a second. The border and other selection highlights stay steady. The pulse stops when Inspector loses focus. Double-click an effect row to open its E1 editor. Double-click on the appropriate item is the future entry point for Piano Roll, Pattern Editor and Automation Editor. The timeline fills the available height. Editors start closed and appear as slide-up overlays (~200–250 ms).
- UAT retains global edit/selection/move/size controls, focus semantics, Undo/Redo and compatibility validation. Clip-specific Duplicate, Clone and Loop belong in Inspector. UAT owns Split and Trim. Glue and Group/Ungroup remain deferred.
- E1 parallel branch owns Effects Editor and effect parameter UI. v0.23.1 owns Inspector chain rows/selection/actions and must use shared effect instance IDs. Avoid competing changes to E1-owned UI.

## Track Inspector — top to bottom
1. Identity: read-only track number/type e.g. 3A (Audio), 3M (MIDI); editable name; color swatch. Explicit fixed type; compatible clips only.
2. Input selector below name.
3. Large MUTE, SOLO and RECORD ARM toggles. Track List displays status indicators only; no duplicate M/S/R buttons. Monitoring on armed tracks follows approved recording spec; reconcile existing behavior before modifying.
4. Wide vertical volume fader integrated visually with **independent live meter**, large handle and numeric dB. Fader position does not control meter scaling.
5. Horizontal PAN slider, L100–Center–R100.
6. Built-in 3-band EQ, independent of eight insert-effect slots: LOW shelf at 100 Hz, MID bell at 1 kHz, HIGH shelf at 10 kHz, each horizontal ±12 dB centered on 0. EQ automation deferred.
7. Effects chain: up to eight user effects; full-width colored rows, standard selection/focus border; disabled rows retain full color, enable/disable button alone changes color. ADD, DELETE, MOVE UP/DOWN, ENABLE/DISABLE. Double-click opens E1-owned Effects Editor; do not duplicate parameter controls. Preserve native/external plugin handling and serialized IDs.
8. Automation: Volume and Pan initially, subject to original automation-lane count and later automation-editor branch; do not assert an unverified four-lane limit. Inspector may expose existing automation controls without inventing an automation editor.
9. Output selector last: one exclusive destination Master (default), Bus 1 or Bus 2; buses feed Master and have volume/pan/effects; **no aux sends/returns**. Future one-level parent/child routing is separate and deferred.
- Track Inspector COPY SETTINGS/APPLY SETTINGS, when implemented, follows latest v0.22.2 override (volume, pan, effects/values, output; preserve identity, clips, automation, inputs, arm, mute/solo, height; atomic validation). Full track duplication stays UAT Track COPY/PASTE, not Inspector Duplicate Track.
- Per-track MIN/MAX height control belongs to Inspector; preserve existing global behavior as appropriate.

## Common Clip Inspector
- Editable clip name; read-only type, assigned track, Start and Length (no End or numeric Start/Length edits). Timeline/UAT moves and sizes clips.
- Ordinary clips inherit the current track color, including after move, paste, duplicate, or Unclone. Linked clips use the parent clip color across tracks.
- Clip trims non-destructive and reversible: hidden source retained on both ends; re-extension reveals it; undoable and persistent.
- MAX track height: waveform, clip names, small amber square centered vertically on each trimmed edge, detailed audio envelope and applicable clone/group/loop markers. Trim squares are indicators, **not drag handles**. MIN: keep waveform for alignment, clip color, selection/focus and name if room; hide trim markers, group/clone/loop badges and gain/fade envelopes. White reserved for focus/playhead, not audio envelope.
- Glue and Group/Ungroup are UAT MODIFY actions: Glue requires ≥2 clips on one track; Group can span tracks; Group/Ungroup label contextual. Group ID distinct from Clone ID.
- Overlapping audio always sums before track processing. Legacy REPLACE properties are ignored on load.

## Audio Clip Inspector
- Clip Gain: horizontal slider and numeric dB, default 0, undoable/persistent.
- Fade In and Fade Out: horizontal sliders in seconds, default 0, linear; combined durations cannot exceed clip duration. When Loop enabled, **fade controls disabled**, preserving values for when Loop disabled. No fade dip on each repetition.
- Bright cyan waveform gain/fade envelope on MAX only; line follows gain, rises/falls at fade ends; independent of white focus/playhead.

## MIDI Clip Inspector
- All ordinary MIDI tracks, melodic or percussion, use future Piano Roll; future Master Drum Track and Pattern Editor are distinct and deferred.
- Clip Velocity (%) slider 0–200%, default 100% centered. Scale note velocity only at playback, preserving original note velocities in source; clamp to 1–127, 0% suppresses Note On.
- Clip Transpose semitone adjustment −24 to +24, default 0; playback only; Piano Roll notes stay at original pitches; constrain MIDI output to 0–127.
- MIDI clip may contain empty time before/after notes. Piano Roll cannot create notes beyond clip boundaries. Trimming hides out-of-bounds notes non-destructively; notes crossing clip end stop at boundary and restore original duration on re-extension.
- Both parameters undoable and saved. Audio-only gain/fades do not appear on MIDI.

## Duplicate, Clone, Unclone
- DUPLICATE: independent copy of source, including entire loop arrangement/settings, placed at timeline cursor on selected clip's track; editable independently; no link icon.
- CLONE: exact linked replica of parent content and editable clip properties, including name, color, mute, trim, pattern length, Loop Enable/Count, audio gain and MIDI velocity/transpose. Place at timeline cursor on source track; may be independently selected and **moved in time or to another compatible track**. Clone uses destination track's instrument, EQ, effects, volume, pan and routing.
- Clone itself is not independently editable except position/track. Selecting a clone displays parent's name plus numbered amber chain-link symbol and clone number in Inspector; editing its properties accesses/changes the shared parent and propagates to all clones. Selecting one clone highlights only it, not its family.
- All members of same clone family show shared numbered chain-link identification on MAX timeline, distinct from numbered clip groups. No clone/group markers at MIN height.
- Inspector supplies **UNCLONE** for every linked family member; converts selected clone into independent editable clip preserving position, content, color and loop arrangement. Undo restores relationship.
- Deleting original parent promotes a remaining clone to editable parent; other clones remain linked, retain their independent positions/tracks. If only one member remains, hide clone badge and treat it as ordinary clip. Undo restores original parent/links.
- Moving parent changes only its own track/position; clones remain in place. Parent edits propagate everywhere.

## Loop (audio and MIDI)
- Clip Inspector has LOOP enable toggle and positive integer LOOP COUNT with no arbitrary maximum (bounded by valid project timeline). Count includes original pattern.
- On enabling Loop, the **current source clip length** is captured/used as pattern length. Repetitions always extend right. Total length = pattern length × count. Changing count immediately resizes total clip; disabling Loop restores single-pattern length; enabling again uses stored count.
- UAT SIZE on looped clip adjusts **parent pattern length**, all repetitions follow; clone families follow parent size/count. Loop repetitions are not individually selectable or editable; clicking one selects/edits parent. They are part of one clip.
- All loop repetitions mirror parent’s audio gain and mute or MIDI velocity/transpose; audio fades disabled during Loop. Looped clone copies full parent loop arrangement and follows all parent edits. Duplicate copies arrangement independently.
- On MAX timeline, display an **equal sign (=) bridging each repetition boundary**; no = on separate clones. Chain-link icon is exclusively for clones. MIN hides both. Persist/undo loop state.

## Import versus Insert menu contract
- **Insert → MIDI Clip** already exists; retain unchanged. It creates blank MIDI for future Piano Roll editing; do not reimplement.
- **File → Import MIDI** is NEW for v0.23.1 test support: import a **single-track** .mid file into selected compatible MIDI track at timeline cursor; preserve note timing and velocities, play through destination instrument, support undo/save/reopen. No multi-track import, automatic track creation or formal MIDI editing.
- **File → Import Audio** is the existing external audio-file import entry and must be retained.
- Remove obsolete **Insert Audio** / Insert Audio File menu entry; no audio creation command in Insert. Do not remove working audio import functionality.
- Handle incompatible destination, invalid file and exceeding timeline/track constraints gracefully; never silently convert clip/track type.

## Approved implementation clarifications
- Inspector owns effect-chain selection and management. Double-click hands off to the E1-owned Effects Editor using the active Edit, Tracktion track identity and plugin EditItemID. E1 owns the editor and parameter controls.
- Master is available in this iteration. Preserve existing non-Master destinations through save/reopen. Bus 1 and Bus 2 are deferred and unavailable in acceptance.
- All hosted audio inserts count toward the eight-slot limit. Built-in EQ is independent. Preserve legacy overflow and block additions whenever the existing count is eight or more.
- Input selection and record arm are separate. Disarming retains the input assignment and disables software monitoring for that destination. Arming uses automatic monitoring. Preserve existing recording behavior and guard against unintended feedback.
- Import accepts exactly one note-bearing track, including a format-1 file with a separate tempo-only conductor track. Retain note pitches, velocities, durations and musical beat positions under the project tempo map. Reject multiple note-bearing tracks with a clear message. No tracks are created.
- The historical Master Spec sets a maximum of four automation lanes per track. Volume and Pan are the initial parameters.

## Deferred and unresolved
- Bottom Piano Roll and Pattern Editor implementation, formal MIDI note creation/editing, Master Drum Track, advanced automation editor, clip time-stretch/playback rate, aux sends and parent/child track hierarchy are out of scope.
- E1 effects editor owns its own UI and tests; integration requires shared effect IDs, serialization and clear ownership.
- If accepted design conflicts with existing engine capabilities or older documents, raise targeted question rather than silently altering semantics.
