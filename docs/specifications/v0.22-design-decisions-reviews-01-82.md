## v0.22.2 Snap OFF toolbar increment — ACCEPTED 2026-11-20

- For Timeline clip MOVE LEFT/RIGHT and SIZE START −/+, END −/+ buttons, **Snap OFF = exactly 10 milliseconds (0.010 seconds) per button press**, independent of musical grid division and tempo.
- With Snap ON, these buttons use **one currently selected grid division** per press, as already planned. Do not reinterpret the 10 ms value as 10 seconds or as a 1/16-note increment.
- For homogeneous multi-clip selections, apply the same signed increment to every selected clip, subject to existing atomic validation and one undoable transaction per button press. Do not alter the established track UP/DOWN step or track-height controls.
- This rule applies to **button actions**; do not change existing mouse-drag Snap OFF behavior.

## Track clipboard and duplicate mapping — ACCEPTED 2026-11-20

- When **Tracks** is the active UAT target, **CUT is disabled**; there is no Cut Track operation.
- **COPY** copies selected track settings, not clips or automation. **PASTE** applies copied track settings to compatible destination track(s), replacing effects/routing/volume/pan while preserving existing clips and automation; reject incompatible destinations atomically. These semantics follow accepted Reviews 32–33. Where multi-track source-to-destination mapping is not specified, request clarification before implementing rather than guessing.
- **DELETE** removes selected track(s) only after the existing required confirmation (Review 31).
- **Duplicate Track** is a separate Track Inspector action, not UAT COPY/PASTE. It duplicates the complete track including clips, effects, routing, and automation, preserving track color and using the approved “ Copy”, “ Copy 2” name suffixes (Reviews 32, 34–35).
- Preserve selection/focus rules and one undoable transaction per completed action. For v0.22.2, do not silently substitute full duplication for settings copy/paste; flag any unimplemented approved behavior in acceptance notes.

## v0.22.2 simplification amendment — ACCEPTED 2026-11-20 (LATEST AUTHORITY)

This amendment **supersedes conflicting earlier reviews, track clipboard addenda, and task-sheet instructions**. Preserve prior text as historical decision record; do not implement superseded group operations.

### Selection and action scope
- **Tracks: single selection only**, including delete, reorder, volume/pan, arm, mute/solo, and settings operations. No multi-track block reorder, multi-track settings clipboard, pairing, or group delete. Delete one selected track with confirmation.
- **Timeline audio and MIDI clips:** retain previously approved multi-selection, including selections across tracks, relative offsets, snapping, compatible destinations, atomic validation and one undo transaction. Multiple selected clips support **CUT, COPY, PASTE, DELETE, MOVE only**. **SIZE and MODIFY require exactly one selected clip**; when multiple are selected, those controls are disabled. Earlier Reviews 23–25 proposing multi-clip split/trim/fades are superseded as to group actions; single-clip editing is not removed.
- **Piano-roll MIDI notes and drum arrangement pattern sections:** retain previously approved multiple-selection behaviors when those editors are implemented, restricted to CUT, COPY, PASTE, DELETE, MOVE. SIZE and MODIFY require a single object. Do not invent editor mechanics not yet specified.
- **Automation points and individual drum hits:** multi-selection deferred; no group operations in this phase.
- Preserve existing selection/focus rules and single-object editing where not contradicted. No need to re-review established multi-clip relative-position and clipboard rules.

### Track UAT clipboard: full duplicate
- With Tracks active, **COPY** captures the **entire selected track**, including clips, automation, effects and parameters, volume/pan, routing, recording input, record-arm state, monitoring state, name and color.
- **PASTE** creates a **new complete track immediately below the track currently selected at paste time**. The new track receives the established unique name suffix ` Copy`, ` Copy 2`, etc.; all other copied state, **including record-arm state**, is retained. Respect the 24-track limit; fail without partial changes if insertion is impossible. One undoable transaction. The copy source and paste insertion anchor may differ.
- **CUT** disabled for Tracks. **DELETE** operates on one track with confirmation. **MOVE UP/DOWN** reorders one selected track; LEFT/RIGHT disabled. **SIZE** disabled for Tracks; track height uses existing controls.
- This **replaces** the earlier UAT track-settings copy/paste and separate Inspector Duplicate Track proposal. Avoid duplicating the full-duplicate function in Inspector.

### Track Inspector: selective settings transfer
- Provide **COPY SETTINGS** on source track and **APPLY SETTINGS** on destination track (one selected track at a time).
- Transfer **volume, pan, effects chain and its parameter values, and output routing**.
- **Do not transfer** mute, solo, input assignment, record arm, input monitoring, name, color, track height, clips, or automation. Existing destination clips and automation remain untouched.
- If applying the new effects chain would invalidate destination effect automation, **reject the entire apply** rather than delete or break automation. No partial change; one undoable transaction for successful apply.
- Explicit automation copy/paste belongs to the **Automation Editor**, not Track Inspector settings transfer.
- Earlier multi-source/multi-destination settings pairing and settings clipboard mapping are superseded.
