## Take editing and grouping (Reviews 60–73) — ACCEPTED, DEFERRED implementation
60 Auto-name Take 1, Take 2 etc; rename in editor.
61 Editor-selected individual take Copy via global UAT; timeline Paste creates independent clip; original retained.
62 Editor Cut take via UAT copies/removes; timeline Paste creates independent clip; cutting last take confirms group deletion.
63 Paste into compatible selected group can add take; timeline Paste creates independent clip. **Low priority**; user questions utility for unrelated musical parts.
64 Timeline Delete group deletes all takes, one undo, no confirmation; editor deletes individual takes.
65 **REVISED by 67:** Split group at playback boundary into two independent groups, with appropriate portions of source recordings available; source recordings not destructively edited.
66 **REVISED by 67:** Trim group playback boundaries; sources remain intact and can be revealed on extension where available.
67 Group-level timeline position, boundaries, fades, gain, Overdub, priority persist when changing active take; take-level content, name, selection change. Inactive takes are not edited or played.
68 Short/partial takes occupy full logical group duration, silent after captured content (no stored silence required).
69 Last recorded take automatically active, even partial; previous takes preserved.
70 Existing selected group can receive additional takes; convenience, lower priority; Keep/Delete applies only to new session.
71 Explicit Add Takes in editor for selected group, armed track; one-session mode; normal Record creates separate material.
72 Loop-enabled recording always creates group, even with only one pass.
73 Add Takes on ordinary clip automatically converts it into group, preserving original as Take 1 and group-level properties; discard new session restores ordinary clip.

## Take limits, audition, Add Takes (Reviews 74–82) — ACCEPTED, DEFERRED implementation
74 Max **16 takes** per group, audio or MIDI; no need to audit 50; delete takes to free capacity.
75 On reaching Take 16, automatically stop recording **and playback**, show limit and Keep/Delete for current session only.
76 Large Previous/Next buttons plus take-name dropdown and Take X of Y indicator; audition selection separate from Set Active.
77 Immediate take audition switching during playback, click-free audio and no stuck MIDI notes; playback position unchanged; Set Active commits.
78 Closing editor without Set Active restores committed active take, without confirmation.
79 Normal Record creates separate clip/group, even when group selected; only Add Takes targets existing group.
80 Add Takes duration uses existing clip/group playback boundaries, no separate time selection; incomplete take has silent remainder.
81 Add Takes playback starts at current edit cursor, not automatically at group beginning; recording begins when entering group; cursor inside begins there.
82 Add Takes monitoring existing take before/after recording window, live input instead during; other tracks continue; click-free.

## v0.22.1 layout decisions (subsequent review)
- Layout Review 01 — **ACCEPTED A:** Replace existing Edit toolbar with permanent UAT near top; transport remains separate; no duplicate editing controls.
- Layout Review 02 — **ACCEPTED B, with clarification:** Two-row **grouped** UAT, not a generic two-row Cut/Copy/Paste grid. Reuse original Universal Actions Integration Specification: titled functional groups EDIT (CREATE/DELETE/COPY/PASTE in 2x2), MOVE (Up/Down/Left/Right), SIZE (START -/+, END -/+), MODIFY (structural editing; exact buttons PENDING). Large equal targets, stable positions, subtle shade differences. Duplicate/Clone/Loop are Inspector Clip Actions rather than permanent UAT buttons. Exact group placement and MODIFY commands remain pending. The prior assistant's seven-button layout was an illustrative error and is NOT approved.

- Layout Review 03 — **ACCEPTED A:** Four groups horizontally side by side in order EDIT | MOVE | SIZE | MODIFY; each has 2×2 action buttons (16 positions total), separated visually, large consistent targets, fixed toolbar location.
- Layout Review 04 — **ACCEPTED A:** Labels/symbols/positions are fixed regardless of active area; dispatch is context-sensitive; unavailable actions gray/inert; active-area border indicates target; no additional status line required.
