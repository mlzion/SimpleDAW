# SimpleDAW v0.22.2 Windows live acceptance

Download the source-paired /MD Windows x64 ZIP from the implementation PR's build results. Record the workflow run, commit, Windows version, audio device and sample rate. Use a disposable project, four existing tracks, a WAV with room to trim, and MIDI clips at different times. Change each status to PASS, FAIL, PARTIAL or UNTESTED and record observations in Comments. For failures, include reproduction steps and expected and observed behavior. [Windows download guide](../windows-download.md)
