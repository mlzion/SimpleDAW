## Windows acceptance entry

Run all checks against the combined Inspector and E1 commit on PR #20. Use a project that already contains a native Compressor for the Compressor controls check. Windows x64 /MD CI requires separate authorization. See the native parameter details in the [E1 test notes](effects-editor-e1.md).
