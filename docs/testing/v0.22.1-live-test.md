# SimpleDAW v0.22.1 Windows live acceptance

Use the Windows x64 artifact from the v0.22.1 pull request. [Download and runtime instructions](../windows-download.md)

Record the workflow run, commit, Windows version and audio device. Mark each numbered check PASS, FAIL, PARTIAL or NOT TESTED. For failures, capture the observed behavior and reproduction steps.

1. Extract the ZIP and launch `SimpleDAW-v0.22.1.exe`. Check the application title. At both the default and minimum window sizes, verify the transport is separate and the former Edit toolbar has been replaced by four horizontal groups in order EDIT, MOVE, SIZE, MODIFY. Verify equal-size targets, two buttons per row in each group, clear separation and two blank disabled MODIFY positions.
2. With no project open, verify all action buttons are gray. Create a disposable project, add two tracks, and import audio clips at distinct times. Insert a MIDI item on an existing track. Confirm the old Insert and File menus still work and that a track with no clip selection gives no enabled EDIT action before the first copy.
3. Left-click a clip, then another. Check that the Timeline border is white, the latest clip alone has a white border and the selected clip retains its color. Right-click a second clip to add it and again to remove it. Check that every selected clip has a white outline, there is no context menu, and Copy and Delete are disabled while there are multiple clips selected.
4. Start a left-drag in empty timeline space and draw a box across two clips. Check during the drag that intersecting clips are selected and that the selection remains when the box disappears on mouse-up. Click empty space to clear the clip selection and move the cursor. Check that the Timeline border remains white.
5. Select a clip, then click a track header. Check that the Tracks border and selected track outline turn white and that the clip keeps its selection color. Right-click another track header to toggle it. Drag from blank space in the Tracks area into the headers to box-select them. Check that Edit commands stay disabled there. Click the ruler to return to Timeline and check the retained clip selection.
6. With a clip selected, click Inspector and then the read-only Effects content. Check that each panel receives a white border and disables editing in Timeline. Hide the focused workspace and check that focus falls back to the selected Timeline clips before Tracks. Reopen the workspace and check that the Timeline retains focus. Check that the unfinished workspace tabs expose no selectable objects.
7. Copy one WAV clip. Check that selection is unchanged. Click empty space on a different existing lane and Paste. Check that the copy starts at the snapped cursor, uses the original media, leaves the original clip intact and becomes selected. Repeat with snap off and a single MIDI item. Check that Paste is disabled after clearing the destination by clicking blank space below all track lanes, and that no tracks are created.
8. Use Edit > Undo and Redo after pasting. Check that a single Undo removes the copy and Redo restores it. Select a middle clip and click Delete. Check that it clears the selection and leaves a gap. Verify one Undo restores the clip. Select a missing-media clip in a disposable project to verify Delete confirmation and access to Edit > Locate File.
9. Check that CREATE, all MOVE and SIZE positions, SPLIT, TRIM and the two reserved positions remain gray and inert on each area. Check that labels and positions stay fixed through selection and focus changes.
10. Drag a single clip on its lane and check snapped preview and commit while stopped. Drag on the ruler to set a loop range. With a clip selected, press Delete and confirm the clip is removed before the range. Press Delete again and confirm the range clears. Check that keyboard Delete in the tempo field retains normal text editing.
11. Start playback, then record a short take with an armed input if hardware is available. Verify actions are disabled while transport plays or records. Stop, save and reopen the project. Confirm audio clips, MIDI items, existing plugin chains, and recorded media still behave as expected. Verify that opening a project clears the clip clipboard.
