# Windows x64 with the dynamic MSVC runtime

The Windows workflow builds both `/MT` and `/MD` from the matching source archive with Visual Studio 2022. The original `/MT` build stays the default. Choose `-DSIMPLEDAW_MSVC_DYNAMIC_RUNTIME=ON` in a fresh CMake build directory to try the dynamic runtime. The same CTest, PE import inspection and isolated startup checks apply to both builds. The dynamic-runtime check allows the installed VC runtime in System32. The hosted runner's successful launch cannot measure availability on a clean Windows installation. [Archived-source build instructions](corresponding-source.md)

## Operating-system and runtime prerequisites

Microsoft ships the Universal C Runtime (UCRT) as a Windows 10 and 11 system component. The Visual C++ v14 C++ standard library and compiler runtime are separately serviced. A Windows machine can already have them from another application or Visual Studio. An `/MD` user needs Microsoft's supported x64 VC++ v14 Redistributable at least as recent as the build tools if a compatible version is absent. The EXE can be moved as one file after that prerequisite is installed. [UCRT deployment](https://learn.microsoft.com/en-us/cpp/windows/universal-crt-deployment) · [Supported VC++ Redistributables](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist/) · [Microsoft x64 download](https://aka.ms/vc14/vc_redist.x64.exe)

## Publication terms

**The qualified form of this path is an EXE-only download with a separately installed Microsoft runtime.** Microsoft's redistribution documentation limits repackaging its redistributable package, merge modules and binaries to licensed Visual Studio users under the product terms and the REDIST list. The proposed SimpleDAW download would carry its own executable and source materials. Users who need the runtime get it from Microsoft and use it under Microsoft's runtime terms. Do not include Microsoft's installer or DLLs in the SimpleDAW download. [Microsoft redistribution conditions](https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files) · [Visual Studio 2022 REDIST list](https://learn.microsoft.com/en-us/visualstudio/releases/2022/redistribution#visual-c-runtime-files) · [Microsoft v14 Runtime terms](https://visualstudio.microsoft.com/license-terms/vs2026-ga-visualcpp-v14-redist-runtime/)

The FSF's Windows guidance treats the dynamically linked Visual C++ runtime as a GPLv3 System Library when supplied separately. AGPLv3 §1 uses the same System Library and Corresponding Source definitions. The matching archive therefore needs the exact SimpleDAW, JUCE, Tracktion and other included source, with build scripts and licences, while the system runtime is separately obtained from Microsoft. Under AGPLv3/GPLv3 §6(d), publish equivalent no-charge access to the matching archive and clear retrieval directions at the binary download location. Include the project and third-party notices, and preserve the source-based SoundTouch relinking instructions. The existing archive pipeline can produce this material. [FSF Windows runtime guidance](https://www.gnu.org/licenses/gpl-faq.html#WindowsRuntimeAndGPL) · [AGPLv3](https://www.gnu.org/licenses/agpl-3.0.en.html) · [Third-party notices](../THIRD_PARTY_NOTICES.md)
